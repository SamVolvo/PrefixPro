# PrefixPro 2.2.0 — draft release notes

One Java 21 JAR for the intended Spigot/Paper range 1.20.6–26.3, with safe reloads, thread-safe prefix updates, scoreboard coexistence and configurable AFK.

Use Java 21 for older servers and Java 25 for 26.x. LuckPerms remains required. Consult [the test report](../docs/TESTING.md) for exact versions actually tested.

## Upgrade

Stop the server, back up the old JAR/data directory, replace the JAR and restart. Existing settings/messages survive migration. Missing defaults are added with backups. Both reload commands now reload settings/messages safely; they do not replace running plugin code.

AFK can be disabled entirely, or protection, titles, notifications and detection can be configured independently. Names inherit prefix formatting or use LuckPerms name-color metadata. Foreign teams are preserved; conflicting nametags are skipped.
